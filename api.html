1. 핵심 단품 투어 (상세 팩트)

보라카이션 블랙펄 요트호핑투어

기존의 방카(전통배)가 아닌, 넓고 쾌적한 럭셔리 대형 요트(블랙펄 호, 화장실 완비)에서 진행되는 보라카이 요트 호핑투어입니다. 1인 55,000원.

✔ 포함 사항:
  • 블랙펄 요트 탑승 (화장실 있음), 스노클장비 + 오리발 + 구명조끼 대여
  • 식음료: 라면, 주먹밥, 김치, 과일, 핑거푸드 (칵테일, 음료 무제한)
  • 고프로 수중 촬영 지원, 멀미약 제공, 보라카이션 현지 스텝 동행
❌ 불포함 사항:
  • 환경세 100페소 필수 (현지 지불)
  • 여행자 보험, 아쿠아슈즈, 점보크랩밀 추가 옵션(1인 $30)
진행 절차: 개별 미팅(화이트/블라복 비치) -> 요트 승선 및 스노클링 -> 선상 파티 및 간식 -> 선셋 감상 후 개별 해산

시크릿가든 말룸파티 투어

블루라군 계곡 다이빙과 튜빙을 즐길 수 있는 힐링 계곡 투어. 1인 99,000원.

✔ 포함 사항:
  • 말룸파티 이동 왕복 차량, 시크릿가든 입장료, 항구 배값/터미널피/환경세
  • 구명조끼, 카약 대여, 말룸파티 스텝 촬영 서비스
  • 오찬: 한방백숙 한상, 라면, 김치, 과일, 핑거푸드 (맥주, 음료 무제한)
❌ 불포함 사항:
  • 튜빙 비용 1인 350페소 (현지 지불 필수 추천 코스)
  • 가이드 매너팁 1인 100페소 필수
  • 여행자 보험, 닥터피쉬 체험(선택)
진행 절차: 숙소 로비 픽업 -> 블루라군 다이빙 및 물놀이 -> 한방백숙 식사 -> 숙소 샌딩 복귀

공항 왕복 픽업샌딩

칼리보 공항에서 보라카이 리조트까지 전용 차량과 보트로 가장 안전하고 편안하게 이동하는 서비스. 1인 54,900원.

✔ 포함 사항:
  • 보험 가입 차량, 항구 배값, 환경세, 터미널피
  • 생수 1인 1병, 보라카이 맵(지도), 맛집/기념품 할인카드, 아일랜드투어
  • 항구 짐꾼(포터) 서비스 무료 (보라카이션 스텝 케어)
❌ 불포함 사항:
  • 칼리보 공항세 1인 784페소 (현지 지불)
  • 매너팁 인당 100페소
  • 여행자 보험, 무거운 짐(골프백, 서핑보드 등) 이동 시 개당 $5 추가
진행 절차: 공항 픽업 (항공 딜레이 시 끝까지 대기) -> 전용 차량/보트 이동 -> 숙소 앞 드랍 및 안내 자료 증정

리버타드 고래상어 투어

세부까지 갈 필요 없이 보라카이 인근 리버타드에서 만나는 야생 고래상어 수중 투어. 1인 95,000원.

✔ 포함 사항:
  • 보라카이 내 접근성이 좋아 반나절 만에 투어 완료 가능
  • 1:1 전담 안전 케어로 수영을 못해도 구명조끼 입고 관람 가능
  • 고프로 수중 촬영 사진/영상 제공

2. 패키지 요약 (팩트 기반)

아래 패키지들은 위 단품 투어들을 묶어서 개별 예약보다 더 저렴한 특별 할인가로 제공하는 상품입니다.

⭐ 시그니처 패키지 (가장 높은 할인율)

포함 내역: 공항 왕복 픽업샌딩 + 리버타드 고래상어 투어 + 보라카이션 블랙펄 요트호핑투어 + 시크릿가든 말룸파티

고래팩 시리즈

  • 고래팩 A: 리버타드 고래상어 투어 + 공항 왕복 픽업샌딩
  • 고래팩 B: 리버타드 고래상어 투어 + 보라카이션 블랙펄 요트호핑투어
  • 고래팩 C: 리버타드 고래상어 투어 + 시크릿가든 말룸파티
  • 고래팩 D: 리버타드 고래상어 + 픽업샌딩 + 블랙펄 요트호핑투어
  • 고래팩 E: 리버타드 고래상어 + 픽업샌딩 + 시크릿가든 말룸파티

일반 패키지 & 픽샌팩 시리즈

  • 패키지 B: 픽업샌딩 + 블랙펄 요트호핑투어 + 시크릿가든 말룸파티
  • 패키지 C: 픽업샌딩 + 리버타드 고래상어 투어 + 시크릿가든 말룸파티
  • 픽샌팩 A: 픽업샌딩 + 블랙펄 요트호핑투어
  • 픽샌팩 B: 픽업샌딩 + 리버타드 고래상어 투어
